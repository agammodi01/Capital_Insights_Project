# 📈 Capital Insights – Stock Market Analysis Platform  

Capital Insights is a full-scale **financial data analytics project** designed to collect, process, analyze, and visualize large volumes of historical stock market data.

The project replicates a **real-world financial analytics pipeline** using Python, SQL Server, and Power BI to transform raw OHLCV data into actionable investment insights.

## 🧠 Project Overview

Modern financial analytics systems must efficiently handle large datasets, ensure optimized storage, and deliver fast, interactive reporting.  

This project demonstrates how financial data teams:

- Automate stock data ingestion from APIs  
- Perform data cleaning and preprocessing  
- Design optimized database schemas  
- Implement indexing for performance tuning  
- Build interactive dashboards for investment analysis  

The objective is to convert raw market data into **clear, performance-driven insights** for decision-making.

---

## 🎯 Key Objectives

- Analyze historical stock price and trading volume data  
- Calculate returns, percentage changes, and moving averages  
- Compare stock performance across multiple time frames (5D, 1M, YTD, 1Y)  
- Implement incremental data refresh logic  
- Optimize database queries for faster dashboard performance  
- Build a scalable financial analytics solution

---

## 🔄 End-to-End Data Pipeline

1️⃣ Fetch historical stock data using **Yahoo Finance API**  
2️⃣ Clean and preprocess raw data using **Python**  
3️⃣ Store structured data in **SQL Server**  
4️⃣ Apply indexing on key columns (`Symbol`, `TradeDate`)  
5️⃣ Optimize queries for performance improvement  
6️⃣ Connect database to **Power BI**  
7️⃣ Build dynamic dashboards using **DAX measures**  

This pipeline mirrors enterprise-level financial analytics systems.
